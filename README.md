# rd-webtoon-streamer

Web UI to browse, fetch and export webtoon episodes from RIDI accounts you own.
Search by title → pick series → select episodes → download with live progress → read online or export ZIP.

Run: `python3 app.py` (needs `farm_ridi.py`, `farm_worker.py`, `titles.json`; pip install -r requirements.txt)
Optional env: `PORT`, `MAX_WORKERS`, `RIDI_PROXY`.
